# 🌙 Night Comfort // Universal Roblox Visuals

Универсальный скрипт для комфортной игры в Roblox ночью или в тёмной комнате.

- **0% слепоты**: Все тени подсвечены, нет непроглядной чернухи.
- **Анти-пересвет (Anti-Glare)**: Убирает слепящие лучи солнца (`SunRays`), смягчает ядовитый `Bloom` и белые текстуры.
- **Защита глаз (True Tone)**: Мягкий тёплый спектр снимает усталость глаз.
- **Компактная плашка**: Маленький виджет сверху, скрывается по нажатию **`Right Shift`**.

---

### 🚀 Быстрый запуск (Loadstring)

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ryomotik/NightVibe/main/universal_night_vibe.lua"))()
```

### ⚡ Локальный запуск (через executor)

Положи файл `universal_night_vibe.lua` в папку `workspace` или `autoexec` твоего экзекутора:
```lua
loadstring(readfile("universal_night_vibe.lua"))()
```
